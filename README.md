# ELVARAS

### Your timetable organizes your notes.

Elvaras is an independently developed student productivity
application designed to bring academic schedules and study
materials into one organized workspace.

## The Idea

Students often manage their timetables, subjects and notes
across different platforms.

Elvaras aims to connect these academic activities through
one structured system.

Timetable → Subject → Chapter → Lecture → Notes

## Key Features

- Timetable management
- Subject-wise organization
- Chapter and lecture-based notes
- Organized academic workspace
- User authentication

## Technology Stack

- Swift
- SwiftUI
- SwiftData
- Firebase Authentication
- Swift Package Manager

## Platform

Native macOS application.
